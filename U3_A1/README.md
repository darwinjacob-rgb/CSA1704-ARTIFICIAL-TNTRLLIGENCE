# AI Case Study — Knowledge Representation & Reasoning (CSA17, CO3)

Complete solution package for **SIMATS Engineering — Assessment Tool 1, Annexure A: Case Study**
(Course: Artificial Intelligence, Course Code CSA17). Covers all four case studies — Smart
Medical Diagnosis, Autonomous Traffic Management, Agricultural Expert Reasoning, and the
Wumpus World — using propositional logic, FOL, forward/backward chaining, unification, and
resolution refutation, as required by CO3.

## Contents

| # | File | Description |
|---|------|-------------|
| 1 | `Problem_Statement.pdf` | All four case-study questions (a/b/c parts) exactly as issued, plus the evaluation rubric. |
| 2 | `Solution.pdf` | Fully worked, step-by-step solutions to every question — symbol tables, forward/backward chaining traces, unification (MGU), CNF conversions, and resolution refutation proofs. |
| 3 | `inference_engine.py` | Self-contained Python program that programmatically re-derives every result in `Solution.pdf` from scratch (no external logic/Prolog libraries). |
| 4 | `output.png` | Single consolidated figure visualising the reasoning pipeline of all four case studies (generated by `inference_engine.py`). |
| 5 | `Report.pdf` | Technical report: methodology, code architecture, results summary, and rubric-mapped self-assessment. |
| 6 | `README.md` | This file. |

## Running the code

Requirements: Python 3.8+ and `matplotlib` (standard library otherwise).

```bash
pip install matplotlib
python3 inference_engine.py
```

Running the script prints a fully-labelled console trace for all four case studies —
every forward-chaining fact derivation, the backward-chaining goal-reduction tree,
the unification substitution steps, and every resolution step down to the empty
clause — and regenerates `output.png`.

### Module map (`inference_engine.py`)

| Function | Technique | Used in |
|---|---|---|
| `forward_chain()` | Generic Horn-clause forward chaining | Case Study 1, 4 |
| `backward_chain()` | Recursive goal-driven backward chaining | Case Study 1 |
| `unify()` / `unify_var()` | Robinson unification algorithm (MGU) | Case Study 2 |
| `resolve()` / `resolution_refutation()` | Propositional resolution over CNF clauses | Case Study 2, 3 |
| `case_study_1() … case_study_4()` | Case-specific knowledge bases and driver logic | All |
| `build_visual_summary()` | Renders `output.png` | All |

## Case-study summary

## Notes

- All logical derivations are implemented **from first principles** — no Prolog engine, SAT
  solver, or third-party inference library is used — to transparently demonstrate the
  underlying algorithms (forward chaining, backward chaining, unification, resolution) as
  required by the course outcome.
- `Solution.pdf` and `inference_engine.py` were cross-checked against each other; both agree
  on every derived fact and proof in this package.
- Academic integrity: this package is intended as a worked reference / study aid. Please
  adapt reasoning steps in your own words and re-derive proofs independently before
  submission, per your institution's Code of Conduct declaration on the assessment cover
  sheet.
